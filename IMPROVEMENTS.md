## 1. Исправление Facial Thirds (Третьи лица)

### Проблема:
Ранее метрика "Facial Thirds" неправильно вычислялась через Golden Ratio (соотношение лица к ширине, рта к носу и т.д.), что не соответствует истинному определению.

### Решение:
Теперь **Facial Thirds** корректно измеряет равенство трёх вертикальных зон лица:

1. **Верхняя треть** (Upper Third): Линия волос → Глабелла (между бровями)
   - Landmarks: `forehead_top (151)` → `nasion (168)`

2. **Средняя треть** (Middle Third): Глабелла → Субназале (под носом)
   - Landmarks: `nasion (168)` → `subnasale (2)`

3. **Нижняя треть** (Lower Third): Субназале → Подбородок
   - Landmarks: `subnasale (2)` → `chin_bottom (152)`

### Алгоритм оценки:
```typescript
// Вычисляем идеальную длину одной трети
ideal_third = total_face_height / 3

// Вычисляем отклонение каждой зоны от идеала
upper_deviation = |upper_third - ideal_third| / ideal_third
middle_deviation = |middle_third - ideal_third| / ideal_third
lower_deviation = |lower_third - ideal_third| / ideal_third

// Среднее отклонение
avg_deviation = (upper + middle + lower) / 3

// Оценка: 0% отклонения = 100 баллов, 20% отклонения = 0 баллов
score = max(0, 100 - (avg_deviation * 500))
```
