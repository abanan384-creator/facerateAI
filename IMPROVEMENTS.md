## 1. Исправление Facial Thirds (Третьи лица)

### Проблема:
Ранее метрика "Facial Thirds" неправильно вычислялась через Golden Ratio (соотношение лица к ширине, рта к носу и т.д.), что не соответствует истинному определению.

### Решение:
Теперь **Facial Thirds** корректно измеряет равенство трёх вертикальных зон лица:

1. **Верхняя треть** (Upper Third): Линия волос → Глабелла (между бровями)
   - Landmarks: `forehead_top (10)` → `nasion (168)`

2. **Средняя треть** (Middle Third): Глабелла → Субназале (под носом)
   - Landmarks: `nasion (168)` → `subnasale (2)`

3. **Нижняя треть** (Lower Third): Субназале → Подбородок
   - Landmarks: `subnasale (2)` → `chin_bottom (152)`

### Алгоритм оценки:
```typescript
// Вычисляем идеальную длину одной трети
ideal_third = total_face_height / 3

// Вычисляем отклонение каждой зоны от идеала
upper_deviation = |upper_third - ideal_third| / ideal_third
middle_deviation = |middle_third - ideal_third| / ideal_third
lower_deviation = |lower_third - ideal_third| / ideal_third

// Среднее отклонение
avg_deviation = (upper + middle + lower) / 3

// Оценка: 0% отклонения = 100 баллов, 20% отклонения = 0 баллов
score = max(0, 100 - (avg_deviation * 500))
```

### Файл: `lib/analyzeFace.ts` (строки 126-155)

## 2. Улучшенный анализ кожи лица

### Проблема:
Предыдущая версия анализировала только текстурную гладкость (variance), игнорируя:
- Цветовую неравномерность
- Поры
- Покраснения/акне
- Морщины

### Решение:
Новый **многофакторный анализ кожи** включает 4 параметра:

#### 1. **Texture Smoothness** (Гладкость текстуры) - 30%
- Анализ дисперсии яркости (luma variance)
- Метрика: StdDev кожи
  - Идеальная кожа: `~5-8`
  - Текстурная кожа: `~10-15`
  - Плохая: `>15`
- Формула: `100 - (stdDev * 1.5)`

#### 2. **Color Uniformity** (Равномерность тона) - 25%
- Анализ стандартного отклонения RGB каналов
- Метрика: Color StdDev
  - Ровный тон: `~5-10`
  - Неровный/покраснения: `~15-25`
  - Очень неровный: `>30`
- Формула: `100 - (colorStdDev * 3)`

#### 3. **Pore Visibility** (Видимость пор) - 20%
- Анализ высокочастотных градиентов (fine details)
- Метрика: Average gradient
  - Гладкая кожа: `2-5`
  - Видимые поры: `8-15`
  - Очень видимые: `>20`
- Формула: `100 - (avgGradient * 4)`

#### 4. **Redness/Blemish Detection** (Покраснения/Акне) - 25%
- Детекция красноватых пикселей (R > G+15 && R > B+15)
- Если >10% пикселей красноватые, штраф:
  - Формула: `rednessScore -= (redRatio - 0.1) * 500`

### Финальная оценка:
```typescript
final_score = texture * 0.30 + color * 0.25 + pores * 0.20 + redness * 0.25
```

### Файл: `lib/quality.ts` (строки 98-271)
